# Joolish - Portfolio Website

Welcome to your portfolio repository! This repo contains three different approaches to building your portfolio website.

## Branches

### 1. **html-css-js** - Static HTML/CSS/JavaScript
A lightweight, vanilla JavaScript portfolio. Perfect for quick deployment and learning.
- No build tools needed
- Deploy directly to GitHub Pages
- Fast and simple

### 2. **react** - React Portfolio
A modern, component-based portfolio built with React.
- Reusable components
- State management
- Easy to expand and customize

### 3. **nextjs** - Next.js Portfolio
A full-stack portfolio with Next.js optimizations.
- Server-side rendering
- Built-in optimizations
- API routes support
- Easy deployment to Vercel

## Getting Started

Checkout the branch you want to use:

```bash
git checkout html-css-js
# or
git checkout react
# or
git checkout nextjs
```

Follow the README in each branch for setup instructions.

---

**Choose your path and start building your portfolio!**
